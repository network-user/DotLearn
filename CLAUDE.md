# Claude Code

Прочитай [AGENTS.md](AGENTS.md) перед любой задачей в этом репозитории. Это единый источник правды по сборке, тестам, архитектуре и конвенциям.

## Приоритет контекста

1. Явный запрос пользователя
2. [AGENTS.md](AGENTS.md)
3. [README.md](README.md)
4. Код в затронутых файлах

## Триггеры

- «Обнови README» / «сгенерируй README» / правки документации: скилл `generate-readme` (стандарт DotCore, с пересчётом LoC).
- «Обнови AGENTS.md» / «синхронизируй правила проекта» (только правила, без README): скилл `sync-project-rules`.
- Глобальные изменения (команды, модули, пакеты, зависимости, архитектура, runtime, точки входа): обнови README через `generate-readme` и правила через `sync-project-rules`.
- «Добавь тему» / уроки, упражнения, курс: скилл `lesson-forge`. Не генерируй контент темы вручную.

Не дублируй содержимое AGENTS.md здесь.
