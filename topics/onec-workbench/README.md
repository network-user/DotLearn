Учебный стенд в браузере: справочники, поступление, реализация с запретом отрицательного остатка, пометка удаления, отчёт и короткая консоль запроса. Интерфейс близкий к управляемому приложению по схеме экранов, но это отдельная программа без знака и логотипа 1С. Зачёт гибридный: шаги должны когда-то стать истинными, а в конце сверяется состояние базы.
